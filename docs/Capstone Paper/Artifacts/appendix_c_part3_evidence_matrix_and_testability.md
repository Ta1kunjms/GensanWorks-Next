## 3. Environment, Mocks, and External-Service Isolation Audit

   - `tests/matching-narrative-rbac.test.ts`: Replaces NextAuth session getter using `__setMockAuthSession`, stubs Supabase database queries (`supabaseAdmin.from`), and replaces `ExplanationService.generateNarrative` with a deterministic stub response ([`tests/matching-narrative-rbac.test.ts#L65-L120`](file:///d:/Personal_Projects/GensanWorks/tests/matching-narrative-rbac.test.ts#L65-L120)).
   - `tests/professor-fixes.test.ts`: Injects mock database objects (`mockDb`) with resolved promises for `auditFormCompletionBias` ([`tests/professor-fixes.test.ts#L155-L163`](file:///d:/Personal_Projects/GensanWorks/tests/professor-fixes.test.ts#L155-L163)).
   - `tests/dashboard-data.test.ts`: Mocks global `fetch` to supply local JSON payloads without HTTP connections ([`tests/dashboard-data.test.ts#L19-L50`](file:///d:/Personal_Projects/GensanWorks/tests/dashboard-data.test.ts#L19-L50)).
   - `tests/admin-jobseeker-password-reset.test.ts`: Injects stub functions for DB lookup and password updates ([`tests/admin-jobseeker-password-reset.test.ts#L20-L29`](file:///d:/Personal_Projects/GensanWorks/tests/admin-jobseeker-password-reset.test.ts#L20-L29)).
2. **External LLM Isolation**:
   - Unit test execution (`matching-engine.test.ts`, `bias.test.ts`, `professor-fixes.test.ts`, `matching-narrative-rbac.test.ts`) does **NOT** issue live network requests to external LLM providers (Groq API or OpenRouter API).
   - Scoring formulas, de-identification transformations, and vagueness penalties operate 100% in-memory.
   - Live external LLM calls are strictly confined to CLI scripts (`scripts/test-matching-agent.ts`), which are executed independently of the automated test runner.
3. **Environment Security**:
   - Unit test suites inject fallback environment values when run locally (`NEXT_PUBLIC_SUPABASE_URL = "https://mock.supabase.co"`, `NEXT_PUBLIC_SUPABASE_ANON_KEY = "mock-key"`, `NODE_ENV = "test"`).
   - HTTP smoke tests require base URL environment variables (`PHASE2_BASE_URL` to `PHASE8_BASE_URL`) and skip cleanly (`it.skip`) when unconfigured.
4. **Data Security & Privacy**:
   - All automated unit test suites use synthetic test data fixtures (`seeker-1`, `job-1`, `Angelo Mercado`).
   - No real jobseeker PII or sensitive operational data is exposed or transmitted during automated test suite execution.
